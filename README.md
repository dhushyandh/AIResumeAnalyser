## 📖 Overview

CVPilot is an AI-powered resume platform designed to help job seekers build, optimize, and tailor resumes for modern recruitment systems.

Using Google's Gemini AI, CVPilot provides intelligent resume analysis, ATS scoring, job description matching, AI-powered rewriting, and personalized career suggestions.

Whether you're a student, fresher, or experienced professional, CVPilot helps you create resumes that stand out.
